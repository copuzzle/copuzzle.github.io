# 企业级应用的实践
做一个的企业级软件，可能可能需要考虑很多层面的内容，假如只是一个组织的内部系统，情况可能好点，但如果是一个对外服务的 SaaS 服务，那要要面临的将是更多的挑战。
我这几年从事企业级的项目管理工具，随着业务的不断增长，服务的客户规模越来越大，需求越来越多样，整个软件项目的复杂性也越来越高。
在这个过程中，如何构建一个有效率的，健壮的软件，以及围绕着它的相关工程，这个答案也变得越来越谨慎。

## 难点

回顾过去几年的经历，关于软件部分的难点有：

1. 需要抽象化实现的标品产品来满足不同行业客户的需求
2. 考虑客户的使用场景、规模差异及部署形式差异等做平衡
3. 基于已有的技术模块、能力快速满足产品要求和业务需要
4. 多视角规划架构演进，以应对未来的业务发展和推动产品的升级
