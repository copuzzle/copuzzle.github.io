# 旷日持久的咳

连续4、5年，几乎每天，到了深夜就咳，还学会了提前准备好装痰的容器，因为没准咳得厉害得醒来吐痰，这是发生在小学4年级到初中的事。现在肋骨有两根有点向下凹，大概率是在发育阶段咳的时候肌肉拉扯出来的，当时也因此自卑了好些年。
初中入学的时候，身高一米四多，“还以为他后面长不高了，没想到踢球运动后面还好” 这是妈妈多年后向我复述爸爸曾跟他讲的话， 可能某种程度也解答了当时小伙伴们踢足球到很晚会被家长骂，而我从来不会。

得这病起因是有一次，收割水稻，天气热，中途休息是跟着邻居家小伙伴跳进池塘里玩，呛到水了，感染发烧几天。初中后就慢慢好了，还发现对一氧化碳极度敏感，不清楚相关性。

昨晚看着灯，想的几件尘封多年的事。
